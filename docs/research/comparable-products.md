# Comparable Products (researched 2026-10-25, vendor claims unverified)

Commercial fact-checkers: Originality.ai, Winston AI, Manus, Detecting-ai.com, GetSolved.ai. Citation tooling: scite (shows whether citing papers support, contradict or mention a finding), Consensus, Elicit. Open source: Loki (claim decomposition, check-worthiness, query generation, evidence retrieval, verdict), ClaimCheck, Claim_Verification_Pipeline (verdict only when an NLI model and a RAG LLM agree), SciFact-style repos, aiFactCheck.

RootCause.ai (also listed as Perceptura) is enterprise causal AI over structured data, not document review. Its ontology idea (entities, time, location) is relevant to Claim resolution.

Gaps found: one source argues that no tool checks whether each citation in a finished document supports the sentence it is attached to (unverified beyond that source); no open-source full-stack web app with upload, report UI and Claims graded by evidence type was found; most tools return "supported by what I retrieved", not "true", so Audrey states which Authorities backed each verdict and how strong they are.
